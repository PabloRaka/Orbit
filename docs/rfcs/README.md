# Project Resonon / PhysLM: RFC Index
## Modular Technical Specifications & Subsystems

This directory houses granular **Requests for Comments (RFCs)** that extend the core [Backbone Specifications](../backbone/README.md).

---

## RFC Lifecycle States
- `DRAFT`: Under active discussion and formulation.
- `ACTIVE`: Approved for simulation or hardware prototyping.
- `STABILIZED`: Verified against numerical benchmarks.
- `SUPERSEDED`: Replaced by an updated physical specification.
